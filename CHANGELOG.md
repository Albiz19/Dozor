# Выпуски

## 0.3.0 · кандидат

- С первого запуска выбранной программы одного работающего прокси недостаточно. Нужен проверенный туннель; для режима системной службы VPN проверяется её состояние в начале и в конце проверки.
- Ошибка чтения таблицы IPv6, смена туннеля, сон и истечение срока проверки не дают возобновить процессы по старым сведениям. Мониторинг продолжает работать при открытом меню.
- HTTP-переадресации больше не засчитываются как независимые ответы об IP.
- Добавлен отдельный [консольный прототип для Windows](windows/README.md). Публичная сборка macOS по-прежнему не устанавливает активный системный сетевой фильтр.

## 0.2.1

- Поддержка incy TUN с проверкой выходного IP, идентичности Xray и основного маршрута перед разморозкой.
- Отображение отказов проверки и её тайм-аута в интерфейсе и журнале.

## 0.2 · 13 ноября 2026

- Меню в строке macOS показывает состояние блокировки, внешний IP, страну и время последней проверки сети.
- В разделе «Блокировка» появилась большая кнопка «Приостановить блокировку» с пояснением о новых и уже замороженных процессах. На паузе она меняется на «Возобновить блокировку».
- Выбранные приложения расположены сразу под кнопкой. Если процессы заморожены, их состояние видно даже на паузе.

## 0.1 · 13 ноября 2026

Первый публичный выпуск Dozor для macOS на Apple Silicon.

- Выбор приложений и дочерних процессов, доверенные IPv4/IPv6 и подсети, проверка маршрутов и удержание заморозки после перезапуска.
- Защищённый запуск Claude Code через локальный HTTP-прокси и исходники Network Extension.
- IP в строке меню, история задержки, локальный журнал и Telegram-уведомления с проверкой подтверждения Bot API.
- Проверка стабильных версий GitHub в настройках и установка обновлений через Homebrew.
