# Что перенесено в Dozor 0.4

| Идея и источник | Где пользоваться в Dozor | Поведение |
|---|---|---|
| Восстановление наблюдения после сбоя, [Kordon](https://github.com/ef1m03/kordon) | macOS → Настройки → Перезапускать Дозор после сбоя | Отдельный процесс обнаруживает аварийное завершение и запускает ту же копию Dozor. После штатного выхода, отключения этой настройки или замены приложения перезапуск отменяется. Пока монитор закрыт, возможен трафик. |
| Профили правил, [LuLu](https://objective-see.org/products/lulu.html) | macOS → Блокировка → Профили VPN | Настройте адреса или подсети, службу и порт. Сохраните набор под именем. Чтобы сменить VPN, примените другой профиль. Dozor отзывает прежнее подтверждение и проверяет новый выход. Список приложений остаётся общим. |
| Ручной режим, [Windscribe Firewall](https://windscribe.com/features/firewall) и [Mullvad](https://mullvad.net/en/help/using-mullvad-vpn-app) | macOS → Блокировка → Удерживать до ручного снятия. Команда также доступна в меню Dozor | Останавливает выбранные процессы, даже если VPN подключён. Удержание сохраняется в настройках и действует после перезапуска Dozor. Таймер принудительного закрытия в этом режиме отключён. Снимите удержание, чтобы разрешить возобновление после новой проверки VPN. |
| Объяснение решений, [OpenSnitch](https://github.com/evilsocket/opensnitch) и [Little Snitch](https://obdev.at/products/littlesnitch/index.html) | macOS → Журнал → Решения | Найдите время и причину смены решения. Для разрешённых адресов видна совпавшая запись списка, например 192.0.2.17 → 192.0.2.0/24. В отдельном локальном файле сохраняются последние 100 изменений. |
| Проверка состояния системных правил, [simplewall](https://github.com/henrypp/simplewall) и [IVPN](https://github.com/ivpn/desktop-app) | Windows → `dozor-win status "C:\Lab\client.exe"` | Читает правила Dozor из Windows Filtering Platform для указанной программы отдельно по IPv4 и IPv6. Показывает постоянный запрет и интерфейсы временных разрешений. Можно запрашивать во время работы guard. |
| Проверка настроек системного фильтра | macOS → Блокировка → Системный сетевой фильтр → Проверить конфигурацию фильтра | В сборке с правами Network Extension читает настройки macOS, проверяет идентификатор провайдера, фильтрацию сокетов и порт. Доступность самого расширения и прохождение трафика требуют отдельной проверки в системе с разрешённым расширением. |

При ручной блокировке Dozor приостанавливает процессы. Время между запуском процесса и его обнаружением, данные в очередях ядра и сеть отдельных системных служб остаются за пределами гарантии. Пакетная блокировка всех программ до входа пользователя потребовала бы отдельной реализации. Профили в этой версии относятся к монитору. При изменении выбранных приложений или порта правила подписанного системного фильтра требуется применить отдельно.

## Когда журнал попеременно показывает заморозку и разморозку

С версии 0.4.2 Dozor проверяет доступность IPv6 на Mac заново. Для режима incy с предпочтением IPv4 подходят активный туннель, только локальные IPv6-адреса на интерфейсах, отсутствие маршрутов к внешним IPv6-адресам и успешные контрольные запросы. Старая запись о выходе IPv6 больше не удерживает приложения. Если сайт сообщает IPv6 на запрос через IPv4-интерфейс туннеля, этот внешний адрес также должен входить в разрешённые. Включать неизвестный адрес в список автоматически Dozor не будет. При противоречивых результатах приложения ждут следующей полной проверки.
