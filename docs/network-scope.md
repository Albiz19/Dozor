# Что именно защищает Dozor при работе с CLI

Это анализ публичной документации, а не запись трафика пользователя. Claude Code, его настройки и сеансы не использовались. Фактические соединения зависят от версии, способа установки, провайдера и инструментов проекта.

| Назначение | Примеры из документации | Что это значит для защиты |
|---|---|---|
| Модель и вход | API Anthropic, claude.ai, platform.claude.com, страница входа и SSO в браузере | Проверка двух адресов диагностирует только два маршрута. Браузер, открытый для входа, может быть отдельным приложением. |
| Обновления и расширения | downloads.claude.ai, npm, GitHub; набор зависит от установщика | IP-адреса CDN могут быть общими с другими сервисами. Глобальная блокировка этих CDN затронет посторонние программы. |
| Инструменты и MCP | Локальный процесс через stdio или удалённый HTTP/WebSocket-сервер из конфигурации | Направления могут принадлежать пользователю, а не Anthropic. Дерево процессов защищает только те операции, которые остаются внутри него. |
| Метрики и ошибки | Документация описывает обращения к инфраструктуре Anthropic и сторонним сборщикам | Блокировка по суффиксу одного домена не покрывает все эти запросы. |
| Другие провайдеры и удалённое исполнение | Bedrock, Vertex/Google Cloud, Foundry, шлюз организации или удалённая среда | Часть адресов отличается. Маршруты удалённого компьютера локальный Dozor не контролирует. |

Источники: [сетевая конфигурация и таблица хостов Anthropic](https://code.claude.com/docs/en/network-config), [транспорт и жизненный цикл MCP](https://code.claude.com/docs/en/mcp), [обработка данных и телеметрия](https://code.claude.com/docs/en/data-usage).

**Практический вывод.** Для контроля случайного прямого выхода политика должна ограничивать соединения выбранной программы с момента запуска, включая потомков, независимо от DNS-имени. Прокси из переменной окружения — настройка клиента; не каждый дочерний инструмент обязан её учитывать. Dozor не меняет признаки устройства, не определяет, как сервис классифицирует сессию, и не может обещать, что сервис увидит только определённую страну.

**Граница текущей реализации.** Обычная заморозка реагирует с задержкой; данные в очередях ядра, системный DNS, уже работающий браузер и отдельные службы требуют самостоятельной проверки. Профиль dozor-run ограничивает прямые IP-сокеты потомков до одного локального прокси; процесс прокси, его DNS, выход в интернет и возможная замена слушателя на этом порту остаются отдельной границей доверия. Успех двух HTTPS-проверок не доказывает путь каждого будущего пакета. Системный фильтр в публичной macOS-сборке не активирован.
