# Настройка Dozor

## IP, VPN и заморозка

Укажите в «Блокировка» адреса или CIDR-подсети доверенного выхода, например `203.0.113.12` или `2001:db8:1234::/48` (здесь и далее приведены адреса для документации). Используйте реальные значения, подтверждённые для вашего VPN. Смена страны и совпадение страны в разрешение не входят.

Dozor проверяет прямой маршрут без системного прокси, маршрут с системными настройками, доступный IPv6 и выход к `api.anthropic.com` и `claude.ai` через указанный HTTP-прокси. При раздельной маршрутизации прямой IP может отличаться от VPN и проверка заблокирует работу. Недоступность контрольных сайтов тоже может оставить приложения замороженными.

Верхний переключатель включает автоматическую остановку выбранных приложений. Кнопка «Приостановить блокировку» временно прекращает остановку новых процессов. На паузе эта же кнопка называется «Возобновить блокировку». Ни пауза, ни выключение защиты, ни выход из приложения не дают команду возобновить уже остановленное дерево. Чтобы возобновить его автоматически, нужен подтверждённый системный VPN и свежая успешная проверка всех маршрутов. Конфигурация обычного прокси без службы VPN этого подтверждения не даёт. По умолчанию время заморозки не ограничено. Если включить принудительное закрытие по тайм-ауту, несохранённая работа будет потеряна.

## CLI и системный фильтр

Выберите «Claude Code (CLI)». Для установленного в «Программы» Dozor и HTTP-прокси, слушающего порт 10808, команда выглядит так:

```sh
/Applications/Dozor.app/Contents/MacOS/dozor-run 10808 "$(command -v claude)"
```

Dozor должен быть запущен и недавно подтвердить маршруты. Команда принимает абсолютный путь к программе. Профиль `sandbox-exec` устанавливается до запуска и наследуется потомками. Разрешён TCP к localhost на указанном порту. Прямой запуск CLI отдельно от этой команды не наследует профиль. Запасной прямой выход самого прокси способен вывести трафик из туннеля. Настройте его соответственно. Системные посредники DNS/IPC и реальная работа конкретной учётной записи не проверялись испытанием локальных сокетов.

Системный фильтр предназначен для новых исходящих IP-сокетов выбранных приложений и распознанных потомков. Если приложение уже открыло сокеты, после активации правил перезапустите его. Неопределённый источник также может быть ограничен локальным портом. Для других процессов правило по домену Claude/Anthropic применимо, когда macOS передала имя хоста. После изменения порта или списка целей заново примените правила в подписанной сборке.

## Telegram

1. Создайте собственного бота через [@BotFather](https://t.me/BotFather). В личном чате с новым ботом отправьте `/start`.
2. Получите ID чата из `result[].message.chat.id` метода [getUpdates](https://core.telegram.org/bots/api#getupdates) своего бота. Для группы укажите её ID со знаком минус и дайте боту право отправлять сообщения.
3. Откройте «Настройки → Telegram», введите токен и Chat ID, нажмите «Отправить тестовое сообщение». Ручная проверка работает и при выключенных автоматических уведомлениях.
4. Включите «Сообщать о заморозке и разморозке в Telegram». При остановке в чат поступает название приложения и причина, при возобновлении — подтверждение проверки VPN. Переключатель системных уведомлений macOS управляет только локальным показом.

«Telegram принял сообщение» означает, что Bot API вернул подтверждение `sendMessage`. В журнале видны сбой сети, отказ бота или ограничение запросов. Доставка без интернета невозможна, очереди отложенной отправки в 0.1 нет. Уведомления относятся к действиям с приложениями. История IP, задержек и остальные записи доступны локально.

## Данные и обновления

Настройки, список приостановленных процессов, журнал и история задержки находятся в `~/Library/Application Support/Dozor/`. Токен Telegram хранится локально в `config.json` в открытом виде. При сохранении Dozor устанавливает файлу права владельца. Не прикладывайте его к issue. При включённом мониторинге сайты для определения IP, страны и маршрутов получают сетевые запросы. Telegram получает сообщения, когда пользователь включает эту возможность или нажимает кнопку проверки.

Проверка обновлений по кнопке запрашивает последний стабильный выпуск у GitHub. Для установки из ZIP завершите Dozor, замените пакет в «Программах» и вновь запустите его. Между этими действиями монитор остановлен. Закройте защищаемые сессии перед обновлением, если непрерывность мониторинга для них существенна. При обновлении через Homebrew контрольная сумма проверяется по cask. При ручном скачивании положите ZIP и `SHA256SUMS` в одну папку и выполните `shasum -a 256 -c SHA256SUMS`.

Для собственной сборки с активацией расширения задайте `DOZOR_SIGN_IDENTITY`, `DOZOR_TEAM_ID`, `DOZOR_HOST_PROFILE`, `DOZOR_FILTER_PROFILE`. Для host и extension потребуются соответствующие App IDs, App Group и права Network Extensions, для host также System Extension Install. Подробнее в [документации Apple](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.developer.networking.networkextension).
