# Участие в Dozor

Для небольшой правки достаточно pull request. Для нового способа блокировки или изменения условий разморозки удобно сначала описать сценарий в issue.

1. Сделайте fork и создайте ветку от `main`.
2. На Mac с Apple Silicon установите инструменты сборки командой `xcode-select --install`. Запустите `./build.sh` и `python3 tests/run.py`.
3. Опишите наблюдаемое поведение до и после изменения. Для исправления ошибки добавьте тест, который воспроизводит именно её.

Сетевые тесты используют локальные TCP/UDP-приёмники, тестовый прокси и одноразовые процессы. Тестовые запросы к Telegram обрабатываются в памяти. Сохраните такую изоляцию. Из отчётов и примеров удаляйте токены, Chat ID, личные IP и пути домашнего каталога.

Для выпуска следующей версии используйте [инструкцию сопровождающего](docs/RELEASING.md).
